# 🌐 ریدایرکت یک دامنه به دامنه‌ای دیگر با استفاده از Cloudflare

اگر می‌خواهید تمام ترافیک یک دامنه (شامل مسیرها و پارامترهای کوئری) را به دامنه‌ای دیگر منتقل کنید، Cloudflare دو روش مؤثر برای این کار ارائه می‌دهد: **Redirect Rules** (پیشنهادی) و **Page Rules** (قدیمی‌تر).

---

## ۱. افزودن دامنه به Cloudflare

* وارد پنل Cloudflare خود شوید.
* دامنه‌ی مبدا (یعنی دامنه‌ای که می‌خواهید از آن ریدایرکت انجام شود) را اضافه کنید، اگر هنوز این کار را نکرده‌اید.
* مطمئن شوید دامنه در Cloudflare فعال شده است (Nameserverها تنظیم شده باشند و وضعیت DNS به‌صورت **پراکسی شده / Proxied** باشد).

---

## ۲. افزودن رکوردهای DNS پراکسی‌شده

برای اینکه Cloudflare بتواند ریدایرکت را اجرا کند، باید رکوردهای DNS آن دامنه به‌صورت "پراکسی‌شده" (آیکن ابر نارنجی) باشند. اگر سروری ندارید، می‌توانید از IP فرضی استفاده کنید:

* وارد تب **DNS** شوید.
* دو رکورد **A** با اطلاعات زیر اضافه کنید:

  | نام (Name) | نوع (Type) | IP مقصد (Content) | وضعیت پراکسی (Proxy Status) |
  | ---------- | ---------- | ----------------- | --------------------------- |
  | @          | A          | 192.0.2.1         | Proxied 🔶                  |
  | www        | A          | 192.0.2.1         | Proxied 🔶                  |

> این IP فقط برای مقاصد آموزشی استفاده می‌شود و ترافیکی را پاسخ نمی‌دهد؛ ریدایرکت پیش از رسیدن به سرور اتفاق می‌افتد.

---

## ۳. انتخاب روش ریدایرکت

برای انجام ریدایرکت، Cloudflare دو روش ارائه می‌دهد:

### 🔸 روش اول: **Redirect Rules** (پیشنهادی)

* از منوی کناری به بخش **Rules** بروید.
* روی **Redirect Rules** کلیک کنید.
* گزینه‌ی **Create Rule** → **Redirect Rule** را انتخاب کنید.

### 🔹 روش دوم: **Page Rules** (برای نسخه‌های قدیمی‌تر)

* اگر پلن شما از Redirect Rules پشتیبانی نمی‌کند:
* به **Rules** → **Page Rules** بروید.
* گزینه‌ی **Create Page Rule** را انتخاب کنید.

> ⚠️ توجه: Cloudflare توصیه می‌کند از Redirect Rules در تنظیمات جدید استفاده کنید.

---

## ۴. تنظیم ریدایرکت

### 🔸 اگر از **Redirect Rules** استفاده می‌کنید:
* **Rule Name:** مثلاً `ریدایرکت کامل دامنه`
* **Condition:**

  * **Field:** `Hostname`
  * **Operator:** `equals`
  * **Value:** `yourdomain.com`
    
  (در صورت نیاز، یک شرط دیگر برای `www.yourdomain.com` اضافه کنید)
* **Action:**

  * **Type:** `Static Redirect`
  * **Status Code:** `301 - Permanent Redirect` (or `302` if temporary)
  * **Target URL:**

    ```
    https://newdomain.com/{path}?{query}
    ```

> این ساختار باعث می‌شود آدرس `yourdomain.com/page?x=1` به `newdomain.com/page?x=1` منتقل شود.

---

### 🔹 اگر از **Page Rules** استفاده می‌کنید:
* **URL Pattern:**

  ```
  *yourdomain.com/*
  ```
  (این هم دامنه خالی و هم دامنه با www را ساپورت می‌کند.)

* **Setting:** `Forwarding URL`
* **Status Code:** `301 - Permanent Redirect`
* **Destination URL:**

  ```
  https://newdomain.com/$1
  ```

> `$1` بخش wildcard مسیر URL را نگه می‌دارد؛ مثلاً `/about` به `/about` در دامنه‌ی جدید منتقل می‌شود.

---

## ۵. انتشار و تست

* روی **Deploy Rule** یا **Save and Deploy Page Rule** کلیک کنید.
* یک پنجره‌ی مرورگر ناشناس (Incognito) باز کنید.
* تست کنید:

  * `http://yourdomain.com/`
  * `http://yourdomain.com/some-page?query=test`
* باید منتقل شوید به:

  * `https://newdomain.com/`
  * `https://newdomain.com/some-page?query=test`

> 🔍 نکته‌ی حرفه‌ای: از ابزارهایی مثل [httpstatus.io](https://httpstatus.io) برای بررسی وضعیت ریدایرکت استفاده کنید.
